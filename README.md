# 家計簿アプリ (Kakeibo-app)

Google Apps Script (GAS) と Google スプレッドシートをバックエンドおよびデータベースとして活用した、スマートフォン・PC対応のレスポンシブ Web 家計簿アプリケーションです。

日々の収支（収入・支出）の素早い記録から、月別のカテゴリ別集計・ドーナツグラフによる可視化、Web画面上でのカテゴリマスターメンテナンス、さらには定期レポートメールの自動配信までを一元的に管理できます。

---

## 1. 主な機能

### ① 収支登録機能（「入力」タブ）
- **直感的なフォーム入力**: 日付（初期値は当日）、収支区分（支出 / 収入）、カテゴリ、金額、メモを入力してGoogleスプレッドシートの「履歴」シートへ即座に記録します。
- **排他制御とデータ保護**: 共通ライブラリ `SharedLib.withLock`（`LockService`）による自動リトライ・排他制御により、複数端末からの同時記録時にもデータの競合・破損を防止します。
- **支出金額の自動符号化**: 区分が「支出」の場合は自動的にマイナス金額として記録し、「収入」の場合はプラス金額として記録します。

### ② カテゴリプルダウンの自動ソート機能（登録件数降順）
- **利用頻度順の自動並び替え**: 「入力」タブのカテゴリ選択プルダウンおよび「履歴」タブの検索フィルター内カテゴリプルダウンは、「履歴」シート全期間の**各カテゴリの登録件数（出現回数）が多い順（降順）**に自動ソートされます。
- **同数時の定義順維持（安定ソート）**: 登録件数が同じカテゴリ同士（登録件数0件の新規カテゴリを含む）は、カテゴリ管理画面（マスター）で設定された定義順を維持します。
- **リアルタイム動的更新**: 初回画面表示時だけでなく、収支データの登録完了時やカテゴリメンテナンス保存時にも、ページをリロードすることなく最新の登録件数に基づいた並び順へ動的に更新されます。

### ③ 月別集計履歴・グラフ可視化機能（「履歴」タブ）
- **高速なクライアントサイドフィルタリング**: 対象年月（過去12ヶ月分）を選択すると該当月の全明細を取得し、「収支区分（すべて / 支出 / 収入）」や「カテゴリ」の切り替え時はサーバー通信なしで即座に再計算・再描画します。
- **カテゴリ別集計 & ドーナツグラフ**:
  - 総収入・総支出・収支差額の概要カード表示
  - **Chart.js** を用いたカテゴリ別割合のドーナツグラフ（支出 / 収入の切り替え対応）および金額・構成比（%）付きの凡例表示
  - カテゴリ別合計金額テーブル
- **日別明細一覧**: 日付昇順で並んだ明細リスト（日付・区分バッジ・カテゴリ・金額・メモ）をスクロール可能なテーブルで確認できます。

### ④ アプリ設定・カテゴリメンテナンス機能（「設定」タブ）
- **管理者パスワード認証**: 設定の閲覧・変更は管理者パスワードによって保護されます（初期パスワード: `admin`）。
- **基本設定サブタブ**:
  - 連携先 Google スプレッドシートID の設定・変更
  - レポート送信先メールアドレスの設定・変更
  - 管理者パスワードの変更
- **カテゴリ管理（メンテナンス）サブタブ**:
  - 現在のマスターカテゴリ一覧（定義順）および各カテゴリの履歴登録件数バッジ `(N件)` の確認
  - **新規追加**: 新しいカテゴリ名の追加
  - **名称編集・並び替え**: 既存カテゴリ名の直接編集、および「▲」「▼」ボタンによる定義順（同数時の優先順位）の入れ替え
  - **削除**: 不要になったカテゴリの削除（※過去の「履歴」シート上の記録データは削除・変更されずそのまま保全されます）
  - **スプレッドシートへの永続化**: 保存ボタンを押すと、バリデーション（空文字・重複・0件防止）を経た上で、スプレッドシート「入力」シートの `B3` セルのデータ入力規則（`VALUE_IN_LIST`）へ直接書き込まれ、画面内のプルダウンにも即時反映されます。

### ⑤ 定期レポートメール自動通知機能
- GASの時間主導型トリガーを設定することで、指定した通知先メールアドレスへHTML形式の集計レポート（総収入・総支出・収支差引・カテゴリ別内訳ピボットテーブル）を自動送信できます。
  - `sendWeeklyReport()`: 週次レポート（直近7日間の集計）
  - `sendMonthlyReport()`: 月次レポート（前月1日〜末日の集計）

## 3. スプレッドシートの構成要件

連携する Google スプレッドシートには、以下の2つのシートを配置してください。

### 1. 「入力」シート
- **`B3` セル**: カテゴリのマスター一覧を保持するデータ入力規則（プルダウン）セルとして使用されます。
  - Webアプリの「設定 ＞ カテゴリ管理」からカテゴリを保存すると、`B3` セルのデータ入力規則が自動的に「リストを直接指定（`VALUE_IN_LIST`）」として更新されます。
  - 初期状態で `B3` セルに入力規則が設定されていない場合は、`Config.js` のデフォルトカテゴリ（`食費`, `日用品`, `交際費`, `交通費`, `水道光熱費`, `その他`）が自動的に使用されます。

### 2. 「履歴」シート
- **1行目（ヘッダー行）**: 以下の列名を1行目に設定してください。

| 列 | A列 (1) | B列 (2) | C列 (3) | D列 (4) | E列 (5) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **ヘッダー名** | `日付` | `区分` | `カテゴリ` | `金額` | `メモ` |
| **データ例** | `2026/10/18` | `支出` | `食費` | `-1200` | `ランチ` |

- **2行目以降**: アプリから登録された収支データが順次追記されます。

## 4. セットアップ・デプロイ手順

### Step 1: ソースコードのプッシュ
1. Node.js 環境で `@google/clasp` がインストール・ログイン済みであることを確認します。
2. プロジェクトルートで以下のコマンドを実行し、GAS プロジェクトへソースコードをプッシュします。
   ```bash
   clasp push
   ```

### Step 2: Webアプリとしてデプロイ
1. Google Apps Script エディタを開きます（`clasp open`）。
2. 右上の **「デプロイ」＞「新しいデプロイ」** を選択します。
3. 種類の選択（歯車アイコン）で **「ウェブアプリ」** を選択し、以下の通り設定してデプロイします。
   - **次のユーザーとして実行**: `アクセスしているユーザー`（または運用に合わせて `自分`）
   - **アクセスできるユーザー**: 運用に合わせて選択（`全員` または特定ユーザー）
4. 発行された Web アプリの URL にブラウザからアクセスします。

### Step 3: 初回アプリ設定（スプレッドシート連携・カテゴリ設定）
1. Web アプリ画面上部の **「設定」** タブを開きます。
2. パスワード入力欄に初期パスワード **`admin`** を入力し、**「認証する」** を押します。
3. **「基本設定」** サブタブにて以下を入力し、**「設定を保存する」** を押します。
   - **スプレッドシートID**: 家計簿用 Google スプレッドシートの ID（URL の `/d/` と `/edit` の間の文字列）
   - **通知先メールアドレス**: 定期レポートを受け取るメールアドレス
   - **新しい管理者パスワード**: 任意の安全なパスワードに変更（推奨）
4. 必要に応じて **「カテゴリ管理」** サブタブへ切り替え、カテゴリの追加・編集・並び替えを行って **「カテゴリを保存する」** を押します。

### Step 4: 定期レポートメールのトリガー設定（任意）
週次・月次レポートメールを自動送信する場合は、GAS エディタの左メニュー **「トリガー」（時計アイコン）** から以下のトリガーを追加してください。
- **週次レポート**: 実行する関数 `sendWeeklyReport` / イベントのソース `時間主導型` / `週ベースのタイマー`（例: 毎週月曜 午前8時〜9時）
- **月次レポート**: 実行する関数 `sendMonthlyReport` / イベントのソース `時間主導型` / `月ベースのタイマー`（例: 毎月1日 午前8時〜9時）
